OMEN TIMER — APP PACKAGE

Features
- Focus timer: 50 or 25 minutes.
- Short break: 10 or 5 minutes.
- Long break: 15 or 10 minutes.
- Cycle: Focus → Short break → Focus → Short break → Focus → Long break.
- Start/Pause, Skip, Restart.
- Daily deep-focus goal of 2 hours, 7-day streak table, and current streak.
- Saves focus progress in this browser.
- Installable as an app on Windows and Android when published on HTTPS.

INSTALL ON WINDOWS LAPTOP
1. Extract this ZIP.
2. For a quick preview, open OmenTimer/index.html in your browser.
3. To install it as an app, publish the OmenTimer folder on an HTTPS host such as GitHub Pages.
4. Open the hosted address in Microsoft Edge or Chrome. Use the Install app icon in the address bar or menu.

INSTALL ON ANDROID
1. Open the same hosted HTTPS address in Chrome or Brave.
2. Tap the browser menu (⋮) and choose Install app or Add to Home screen.
3. Confirm. Omen Timer will appear on your home screen.

NOTE
The ZIP itself is not an EXE or APK. It contains the installable web app. To install on both devices, publish it once on HTTPS and open that address on each device. Focus history is stored separately in each browser/device; it does not automatically sync between devices.
